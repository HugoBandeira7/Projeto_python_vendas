# Projeto_python_vendas
Projeto de Automação de Vendas em Python

Este repositório contém códigos e estudos em Python desenvolvidos para simulação e análise de dados de vendas.

### Tecnologias Utilizadas:
* Python
* Jupyter Notebook

### Objetivo do Projeto:
Praticar a manipulação de dados, estruturas de repetição e lógica de programação voltada para cenários de negócios e faturamento.
